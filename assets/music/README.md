# Background music

Place a loopable, copyright-safe music track here as `bgm.mp3` (path is
configurable via `audio.bgm_path` in `config/settings.yaml`).

It is mixed under the voiceover at `audio.bgm_volume_db` and automatically
ducked (sidechain compression) whenever a character speaks. If no file is
present, the video is rendered with voiceover only.

Good sources for channel-safe music: YouTube Audio Library, Pixabay Music,
or a subscription service (Epidemic Sound, Artlist) if you monetize.
